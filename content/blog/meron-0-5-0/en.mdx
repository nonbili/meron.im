<PostSection>

Meron 0.5.0 adds OpenPGP email encryption, separate windows for conversations and drafts, and a reader for saved `.eml` files. Keep a reference email beside your draft, open a composer from the system tray, and switch between tabs without losing your place.

<PlatformNote>The features below are available in desktop 0.5.0. PolicyKit authorization applies to Linux updates.</PlatformNote>

</PostSection>

<PostSection>

<Badge icon="Lock">Security &amp; Privacy</Badge>

## End-to-end OpenPGP encryption with Autocrypt

Send and receive end-to-end encrypted email with OpenPGP. Autocrypt shares public keys through email headers to help compatible clients exchange encrypted messages.

Start under **Settings → Encrypted email**. Generate a key pair for your account or import your existing secret keys from GnuPG, Thunderbird, or OpenKeychain.

- **Choose encryption in the composer:** Once Meron has a key for every recipient, you can send an encrypted message. Use the lock toggle to turn encryption on or off for each message, or enable it by default when keys are available. Replies to encrypted threads use encryption automatically.
- **Check signatures and key status:** Message badges show whether incoming mail is encrypted or signed. Key status labels include Verified, Known, Key changed, and Revoked. Compare a contact's fingerprint with them before marking their key as verified.

## Spread conversations and drafts across screens

Keep an earlier email beside the proposal you're writing, or move a conversation to a second monitor. Conversations and drafts can now open in separate desktop windows.

- **Keep your place in each tab:** Switch between conversations without losing your scroll position, text selection, or unfinished input.

## Open saved emails without importing them

Double-click a saved `.eml` file to open it in a dedicated reader window. Read the formatted message, inspect attachments, and check headers without adding the message to an account.

## Link dialog, board shortcuts, and system polish

The composer, boards, and desktop updates also get a few improvements:

<BlogImage
  src="/screenshots/blog/meron-050-link-dialog.png"
  alt="Meron composer showing the formatting toolbar and the new Link insertion dialog with Link URL input and Save button"
  caption="Insert and customize hyperlink destinations with the new composer link dialog (⌘K / Ctrl+K)."
  width={1280}
  height={820}
/>

- **Composer link dialog:** Press <kbd>⌘K</kbd> (or <kbd>Ctrl+K</kbd>) or click the link icon in the formatting toolbar to insert or edit links with custom display text and destination URLs.
- **Mark a board column as read:** Right-click a Kanban board column header to mark all messages in that column as read.
- **Consistent draft menus:** Edit and discard actions now use consistent menus across message bubbles, thread rows, and composers.
- **PolicyKit on Linux:** Authorize desktop update installation through a PolicyKit prompt without running Meron itself with elevated privileges.
- **Security fixes:** This release tightens how Meron handles email links, cached attachments, and access to desktop runtime handlers from email content.
