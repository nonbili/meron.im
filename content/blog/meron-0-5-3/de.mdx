Eine Einstellung zu ändern sollte schnell gehen – auch wenn man nicht mehr genau weiß, wo sie zu finden ist. In Meron 0.5.3 bringt Sie die Desktop-Befehlspalette direkt zu einzelnen Einstellungen. Dieses Release bietet außerdem anpassbare App-Icon-Farben, das Kopieren von Anmeldecodes mit einem Klick sowie nützliche Änderungen bei Feeds und der mobilen Navigation.

</PostSection>

<PostSection>

<Badge icon="Search">Einstellungssuche</Badge>

## Einstellung finden, langes Suchen sparen

Öffnen Sie die Befehlspalette und tippen Sie den Namen einer Einstellung ein. Die Ergebnisse enthalten nun einzelne Optionen aus den allgemeinen, Konto- und Board-Einstellungen. Wählen Sie eine Option aus, um die **Einstellungen** direkt an dieser Stelle zu öffnen.

Wenn das Suchfeld leer ist, behält die Palette ihre kompakte Aktionsliste. Einstellungen werden eingeblendet, sobald Sie tippen – so sind sie schnell erreichbar, ohne das Menü zu überladen.

## Wählen Sie eine Farbe für Ihr App-Icon

Gehen Sie auf dem Desktop zu **Einstellungen → Erscheinungsbild → Symbolfarbe**, um eine Vorlage auszuwählen oder eine eigene Farbe festzulegen. Unter macOS und Windows erscheint die neue Farbe im Dock oder in der Taskleiste, während Meron läuft. Unter Linux aktualisiert dies das Starter- und Dock-Symbol.

Auch mobile Icons passen sich noch besser an Ihren Startbildschirm an: dunkle und getönte Varianten unter iOS sowie themenbasierte monochrome und Nacht-Icons unter Android.

## Code kopieren und direkt anmelden

Wenn eine Bestätigungs-E-Mail einen Einmalcode enthält, zeigt Meron eine Karte zum **Code kopieren** über dem Nachrichtentext an. So können Sie den Code mit einem Klick kopieren, anstatt die Ziffern manuell zu markieren.

Benachrichtigungen über neue E-Mails enthalten ebenfalls eine Aktion zum **Code kopieren**, und Desktop-Benachrichtigungen zeigen den Code direkt im Text an. Die Code-Erkennung ist auf Desktop und Mobilgeräten verfügbar; Sie können sie unter **Einstellungen → Datenschutz → Einmalcodes erkennen** deaktivieren.

</PostSection>

## Geben Sie Feeds Namen, die für Sie Sinn ergeben

Sie können einen RSS-Feed jetzt beim Bearbeiten in der Feed-Liste auf dem Desktop oder Mobilgerät umbenennen. Wenn Sie den Namen leer lassen, wird der ursprüngliche Titel des Feeds verwendet.

Auf dem Desktop-Kanban-Board haben RSS-Spalten nun eine **+**-Schaltfläche in der Kopfzeile, um einen weiteren Feed unter diesem Konto zu abonnieren. Karten reagieren zudem schneller auf Klicks und Rechtsklicks.

</PostSection>

## Kleine Fehlerbehebungen für den Alltag

- **Mobile Navigation:** Ziehen Sie über das Ende einer Nachricht oder Konversation nach oben, um sie zu schließen.
- **Android:** Abstürze beim Anzeigen sehr großer Bilder behoben und Stabilität des Readers verbessert.
- **Linux:** Entsperren des Keyrings beim Systemstart verbessert, Klicks auf Benachrichtigungen öffnen die richtige Arbeitsfläche und AppImage-Starterintegration korrigiert.
- **Mail-Synchronisierung:** Verzögerungen beim Desktop-Start behoben sowie ein Fall behoben, in dem neue E-Mails beim Neustart einer IMAP-IDLE-Verbindung übersehen werden konnten.
- **Antworten und Sicherheit:** Bildgrößen in Schnellantworten korrigiert und den HTML-Sanitizer aktualisiert, um einen Sicherheitshinweis zu beheben.

Alle weiteren Details finden Sie im [vollständigen Changelog](/changelog).
